# MailMind AI

A local-first email intelligence platform for one Gmail account: read-only by default, with an optional, approval-based Delete list.

* **Local by default:** sync, classification, priority scoring, action and follow-up
  detection, duplicate and newsletter detection, and cleanup suggestions all run on your PC
  with deterministic, configurable rules. No AI is involved.
* **Claude when you ask:** select conversations, preview exactly what will be shared, confirm,
  and analyse with Claude through **Claude Code** (local Skill + MCP server) or, optionally, the
  **Anthropic API**. Results are schema-validated, and every finding links to its source emails.
* **Read-only by default and private:** `gmail.readonly`, a DPAPI-encrypted token, a server on
  `127.0.0.1` only, and a full audit log. MailMind never sends, archives, labels or unsubscribes.
* **Optional Delete list:** after you opt in (`login.ps1 -EnableCleanup`) and approve a preview,
  old mail from chosen senders is moved to Gmail's Trash after each sync. Starred, Important and
  trusted mail is protected, and every run can be undone.
* **Automatic:** optional sync every N minutes (Settings) and start at Windows login (`scriptsutostart.ps1`).
  `scripts\sync.ps1` and the `mailmind-sync` Claude Code skill trigger a sync on demand, for one account or all of them.

## Quick start (Windows)

```powershell
cd D:\Projects\MailMindAI
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
scripts\load_sample_data.ps1        # optional: explore with the synthetic dataset (port 8766)
# put your Google OAuth "Desktop app" client at config\client_secret.json (docs\INSTALL.md)
scripts\login.ps1                   # read-only Gmail consent
scripts\start.ps1                   # http://127.0.0.1:8765
```

## Claude Code

Open the project folder in Claude Code and approve the `mailmind` MCP server, then try:

* `/mailmind run pending analysis 3` (runs a request you confirmed in the dashboard)
* "What did my manager decide about the turbine retrofit?"
* "Compare the two latest client conversations about Atlas"
* "Generate a weekly work email summary"

## Repository layout

```
backend/
  api/            FastAPI app, security middleware, routers
  gmail/          OAuth (auth.py), read-only adapter (client.py), parser, synthetic fixture source
  sync/           sync engine, idempotent ingest, post-sync hook
  intelligence/   rules, classifier, actions, conversation state, pipeline
  cleanup/        recommendation engine (no execution)
  ai/             gateway, context_builder, response_validator, claude_code_bridge, anthropic_api, schemas
  mcp_server/     stdio MCP server (6 tools)
  db/             models, session, repo        security/  DPAPI token store, audit
migrations/       Alembic (0001 schema, 0002 FTS5)
frontend/         React + TypeScript dashboard (Vite)
.claude/skills/mailmind/SKILL.md       Claude Code Skill (analysis)
.claude/skills/mailmind-sync/SKILL.md  Claude Code Skill (sync + cleanup report)
.mcp.json         MCP server registration (regenerated by setup.ps1)
scripts/          setup, start, stop, login, sync, autostart, backup, load_sample_data, run_tests (.ps1)
tests/            pytest suite + synthetic fixtures (tests/fixtures/synthetic_emails.json)
docs/             INSTALL.md, SECURITY.md, ARCHITECTURE.md, REVIEW.md
```
